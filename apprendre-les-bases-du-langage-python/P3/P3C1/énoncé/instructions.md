# Instructions  

1. Dans le fichier `operations.py`, **créez** une fonction `addition(a, b)` qui retourne la somme de deux nombres `a` et `b`.
2. Toujours dans `operations.py`, **créez** une fonction `multiplication(a, b)` qui retourne le produit de deux nombres `a` et `b`.
3. Dans le fichier `main.py`, **importez** le module `operations`.
4. Dans la fonction `main()` (ou directement dans `main.py`), **appelez** la fonction `addition` pour calculer `3 + 5` et **affichez** le résultat.
5. **Appelez** ensuite la fonction `multiplication` pour calculer `8 * 2` et **affichez** le résultat.
